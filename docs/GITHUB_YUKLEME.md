# GitHub'a yükleme ve başvuru

1. ZIP'i çıkarın. GitHub deposuna bu klasörün **içeriğini** yükleyin: README.md, .gitignore, build.ps1, .cs/.csproj dosyaları, Assets ve docs. ZIP'i tek dosya olarak yüklemek yerine kaynakların depoda görünmesini sağlayın.
2. Depoyu Public yapın. README'deki klonlama adresi AlperenK22/Nasa-Space-Apps-Challenge olarak ayarlandı; farklı depo kullanırsanız güncelleyin.
3. bin, obj, dist, kişisel sağlık kayıtları, test çıktıları ve kullanıcı profilleri kaynak paketine dahil edilmedi. Uygulama dosyalarını paylaşacaksanız GitHub Releases altında ayrı yayımlayabilirsiniz.
4. Gönderdiğiniz formdaki “Proje Tanıtımı” alanı kaynak koddan ayrı bir demo istiyor: başlık ve giriş dahil en fazla 7 slayt veya en fazla 30 saniyelik video.
5. Bu alana bitmiş demo videosunun veya sunumunun herkese açık, tam https:// bağlantısını girin. Kaynak kod deposu tek başına demo yerine geçmeyebilir. Bağlantıyı oturum kapalı/gizli pencerede kontrol edin.

Bu paket GitHub'a otomatik yükleme yapmaz. Ana uygulama dosyalarınız değiştirilmedi.
