Records use the crew member and environment selected above. Units are fixed; empty fields are not measurements. Manual entry does not imply a sensor connection or medical verification. Records are stored in an encrypted local file tied to the Windows user.

Report reference interval (optional)

Reference units match the selected measurement. If report-specific limits are omitted, supported measurements use a sourced general adult interval. An out-of-range result alone is not a diagnosis or an emergency.

Bulk CSV import

UTF-8 file; maximum 1 MB / 1,000 rows. Columns: metric,value,unit,measuredAt,source. Use an explicit UTC timestamp: 2026-11-15T08:30:00Z. Records are saved only after all rows pass validation.
